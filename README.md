# NBA Matchup Lab

Independent NBA analytics application exploring player matchups, defensive assignments, matchup difficulty, and lineup context.

**[Launch the application](https://michaelonyemenam-ds.github.io/nba-matchup-lab/)** | [Application source](./apps/index.html)

## Research scope
- Player-versus-player performance and defensive assignments
- Point-of-attack defense and matchup difficulty
- Offensive and defensive strengths in lineup context

This is an experimental analytical interface; individual statistics should be interpreted with their source and validation limitations.

## Run locally
Open `apps/index.html` in a modern browser. Alternatively run `python3 -m http.server 8000` from the repository root and visit http://localhost:8000/apps/.

## Structure
- `index.html`: root redirect for GitHub Pages
- `apps/index.html`: original application, preserved
- `docs/`: project documentation

## Deployment
Select **Settings → Pages → Deploy from a branch → main → /(root)**. The expected URL after successful deployment is https://michaelonyemenam-ds.github.io/nba-matchup-lab/.
