# Matchup Lab — application release notes

This repository is being prepared for an initial, exploratory application release.

## Application

The browser entry point is `apps/index.html`. Download the file and open it in a modern browser; it embeds analytical data and requires no build step. External fonts may require internet access.

**Status:** The HTML application has been committed at `apps/index.html`. Browser testing and live website deployment remain pending.

## Research limitations

Some outputs are labeled PROXY or provisional. These are exploratory associations, not causal estimates. The large source datasets, extraction pipelines, licensing review and full browser testing are not part of this initial release.
